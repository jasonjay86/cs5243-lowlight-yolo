Does low-light enhancement help YOLO detect animals at night?

CS5243 Computer Vision, Fall 2026, Group 4

Jason Johnson, Krutin Patel, Richard Zanni

Presentation Code repository

The question

Camera traps let ecologists monitor wildlife remotely, but night photos are dark, grainy and low-contrast, and detectors miss animals in them. Image enhancement is a common fix, but it is not clear which method helps detection, or whether some add artifacts that make it worse. We compared low-light enhancement methods as a preprocessing step before YOLOv8n on the Caltech Camera Traps dataset (CCT-20).

The methods are CLAHE (classical contrast enhancement), SNR-Aware (a CVPR 2022 transformer) and RetinexFormer (a learned Retinex model), each compared with the raw images.

Data and setup

46,231CCT-20 images in our frozen split
14 / 3 / 3train / val / test camera locations
6,761held-out test images
44,254animal bounding boxes (one class)

The split is location-disjoint: no camera site appears in two splits, so test scores reflect new sites. The detector is YOLOv8n, kept the same for every method. We ran two experiments:

  • Q1, test time: does enhancing the input help a model trained on raw images?
  • Q2, train time: does training the detector on enhanced images beat training on raw?

Metrics are class-agnostic mAP@0.5 with 95% paired bootstrap intervals over test frames, plus precision, recall and the false-positive rate on empty frames.

Results

Intervals are paired bootstrap over test frames and do not include training-seed variance (one training run per model). Only 601 test frames are empty, so false-positive intervals are wide.

What we found

  • No enhancement beat the raw baseline (mAP@0.5 0.914), and every paired 95% interval excludes zero.
  • Enhancing at test time hurts a raw-trained detector: CLAHE −0.080, RetinexFormer −0.401, SNR-Aware −0.465, mostly through lost recall.
  • Retraining on enhanced images recovers most of the loss but not all of it: CLAHE −0.013 (about 84% recovered), RetinexFormer −0.137, SNR-Aware −0.171. The retrained SNR-Aware and RetinexFormer models also have more false positives on empty frames (about 0.30 vs 0.206).

Caveats

  • Scores average over all test frames, day and night. Night-only results may differ.
  • The enhancers are used as pretrained, not fine-tuned on camera-trap data. Fine-tuning them is untested and would need unpaired or self-supervised training, since night frames have no bright counterparts.
  • Each model is a single training run.

Reproduce it

Full setup and commands are in the repository README. In outline, from the repo root:

# 1. environment (see README; GPU nodes need a CUDA 12.6 PyTorch build)
conda env create -f environment.yml

# 2. YOLO dataset from the frozen split
python scripts/prepare_yolo_dataset.py \
  --manifest data/cct20_splits/split_manifest.csv \
  --annotations data/cct20/caltech_bboxes_20200316.json \
  --output data/cct20_yolo --absolute-yaml-path

# 3. enhanced copy of the dataset, then its YOLO dataset
python scripts/enhance_dataset.py --manifest data/cct20_splits/split_manifest.csv \
  --method clahe --output data/cct20_clahe --workers 8
python scripts/prepare_yolo_dataset.py --manifest data/cct20_clahe/split_manifest.csv \
  --annotations data/cct20/caltech_bboxes_20200316.json \
  --output data/cct20_yolo_clahe --absolute-yaml-path

# 4. fine-tune YOLOv8n (Slurm; same settings for every condition)
sbatch scripts/sbatch-yolo-finetuning
sbatch scripts/sbatch-yolo-finetuning-clahe
